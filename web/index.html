Le décompte est recalculé dans votre navigateur à partir de l'historique public de l'urne. Personne n'a besoin de nous croire sur parole : vous pouvez changer l'adresse et recompter n'importe quel scrutin FerraVote.

Comment ça marche

  1. L'organisateur crée un jeton VOTE (MPT) : autorisation obligatoire, pas de transfert entre électeurs, plafond égal au nombre d'inscrits.
  2. Chaque électeur inscrit demande le jeton, l'organisateur valide son adresse après vérification de la liste d'émargement (hors chaîne).
  3. L'urne envoie 1 VOTE à chaque adresse autorisée.
  4. Pour voter, l'électeur renvoie son jeton à l'urne avec le code de sa liste dans le Memo. Son solde tombe à 0, il ne peut plus revoter.
  5. À la clôture l'urne verrouille le jeton : plus aucun bulletin ne passe.
  6. N'importe qui recompte en relisant l'historique de l'urne.

Limites assumées

  • Le vote est pseudonyme, pas secret : le choix est lisible dans le Memo et l'organisateur connaît le lien adresse / personne.
  • L'inscription reste centralisée chez l'organisateur.
  • Testnet uniquement, aucune valeur légale.
